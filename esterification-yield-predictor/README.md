# Esterification Reaction Yield Predictor

This project predicts esterification reaction yield percentage using machine learning techniques based on reaction parameters like temperature, catalyst amount, reaction time, and ethanol ratio.

## Technologies Used

- Python
- pandas
- NumPy
- matplotlib
- scikit-learn

## Features

- Synthetic dataset generation
- Data cleaning
- Exploratory Data Analysis
- Correlation analysis
- Regression modeling
- Yield prediction
- Visualization

## Model Evaluation

- RMSE
- R² Score

## Run Command

python esterification_yield_predictor.py

## Reaction

CH3COOH + C2H5OH → CH3COOC2H5 + H2O
